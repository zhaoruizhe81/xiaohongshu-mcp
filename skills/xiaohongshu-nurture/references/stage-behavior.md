# 阶段 · 权重 · 配额 · 行为

## 阶段
| 值 | 名称 | 大致天数 | 能做什么 |
|---|---|---|---|
| 0 | 观察 | D1-2 | 只刷 feed/看笔记/休息，不互动 |
| 1 | 轻互动 | D3-5 | + 点赞、搜索浏览 |
| 2 | 深化 | D6-10 | + 收藏、逛主页 |
| 3 | 社交 | D11+ | + 评论、看通知 |
| 4 | 创作 | — | 发布（未实现） |

阶段是**人**在后台/DB 里推进，代码不按天自动跳。

## 节奏默认（rhythm.go DefaultPolicy）
- 活跃时段：7-9 / 12-14 / 19-23。
- 每日场次上限：3。
- 会话时长：对数正态，中位 20min，夹 10~45min。
- 动作间隔：8~50s 随机。
- 评论仅在"社交阶段 + 已配 LLM"时有权重。

## 刷 feed 算法（browse.go）
```
刷新首页 → 本轮已看 c=0
循环: 滚 1~3 屏(逐格) → 每屏停 2~6s → 读 __INITIAL_STATE__.feed.feeds 入队并计数
      c >= N(20~50随机) → reload 刷新 → c=0
      滑到底且不再加载 → reload
```
候选笔记进 `Session.queue`，供 like/favorite/comment/open 消费。

## 停留（noteWatch）
- 视频：按 `Video.Capa.Duration` × 30%~80%。
- 图文：`3 + 图片数×2 + 随机` 秒。夹 4~60s。
- 看笔记后约 70% 概率下滑评论区 2~5 屏（`ReadComments`，只滚动+停留、不加载全量）；评论前也会先翻 1~3 屏。

## 评论校验闸（commentgen.validate）
- 长度 8~40 字；正则拦 链接/微信/QQ/11位手机号/价格；与最近 30 条评论 Jaccard>0.7 视为重复。
- 不合格重生成 1 次，仍不过则**跳过不发**。

## 熔断（engine.block）
- 安全验证页 → `status=cooldown`，冷却 24h。
- 登录失效 → `status=paused`，待重登。
- 其它异常 → 冷却 2h。
