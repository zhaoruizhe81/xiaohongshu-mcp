## 改造清单（P0=必须 / P1=建议 / P2=可选）

### P0
1. **有头运行**：本机 macOS 直接可跑（不做服务器/Xvfb）。首次验证有头窗口弹出 + 指纹补丁生效。
2. **常驻会话**：不动 `service.go`；keeper 内 `Session` 自持 `browser+page`，一场会话只开一次。动作层全部接受 `*rod.Page`，直接复用。

### P1
3. **一号参数化（多号才必须）**：cookie 路径写死在 `browser/browser.go:90`（`cookies.GetCookiesFilePath()`）。单号设 `COOKIES_PATH` 即可；多号需给 `browser.NewBrowser` 加 `WithCookiesPath(path)` 选项。代理/seed 已是 Option，按账号直接传。
4. **风控熔断**：`xiaohongshu.CheckPageBlocked(page)`（已导出）作为信号；动作会用 `Must*` 可能 panic，需 `safe()` + recover 兜住。
5. **错误穿透**：确认 `ErrVerificationRequired` / `ErrLoginRequired` 能从动作层传到调用方，供冷却判定。

### P2
6. **拟人入口**：`like_favorite.go` / `comment_feed.go` 现在直接 `MustNavigate(详情URL)`；可从 feed 点卡片进入更像人。
7. 每动作截图留档（复盘封号）/ 一号一住宅IP / 多号独立指纹 / 时段外置。

## 能力缺口（原始底座没有）
- ❌ 关注(follow)：无接口 → 决定不做。
- ❌ feed 滚动浏览：只有 `list_feeds` 快照 → 在 keeper 内用 rod 真滚动实现。
